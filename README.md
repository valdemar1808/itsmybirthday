# Сайт-приглашение на 25-летие (19–20 декабря 2027)

## Что внутри архива
- `index.html` — готовое мобильное веб-приложение (Этапы 1 и 2: капча, приколы кнопки отказа, входящий видеозвонок, задувание 25 свечей в микрофон, генератор VIP-билета с распознаванием лица).
- `assets/child/1.jpg` ... `13.jpg` — 13 уникальных детских фото (дубли убраны, фото с ретро-трубкой повёрнуто ровно).
- `assets/ref/1.jpg` ... `5.jpg` — 5 актуальных эталонных фото для проверки лица при выдаче билета.
- `assets/ai/1.jpg` ... `32.jpg` — 32 сгенерированных нейросетевых аналога для капчи (из-за дневного лимита генерации получилось 32 уникальных кадра — код `index.html` уже настроен ровно на них).
- `README.md` — эта инструкция.

## Куда положить видео звонка
Когда оживишь детское фото своим видео (в LivePortrait / Hedra / CapCut), сохрани его как **`call.mp4`** и положи в папку `assets/call.mp4`. Пока файла нет, на сайте работает встроенный демо-режим звонка с субтитрами.

## Как загрузить сайт на GitHub Pages (за 3 минуты)
1. Зайди на [github.com](https://github.com) и нажми **New repository** (кнопка `+` в правом верхнем углу -> *New repository*).
2. Введи название репозитория, например `birthday-25`, выбери **Public** и нажми **Create repository**.
3. На странице созданного репозитория нажми ссылку **uploading an existing file**.
4. Распакуй этот ZIP-архив на компьютере и перетащи **содержимое папки** (`index.html`, `README.md` и папку `assets` целиком) в окно браузера. Дождись загрузки всех файлов и нажми зелёную кнопку **Commit changes**.
5. Перейди во вкладку **Settings** (вверху репозитория) -> в левом меню выбери **Pages**.
6. В блоке **Build and deployment** -> **Branch** выбери `main` (папка `/ (root)`) и нажми **Save**.
7. Через 1–2 минуты обнови страницу Settings -> Pages: сверху появится твоя рабочая HTTPS-ссылка вида `https://твой-ник.github.io/birthday-25/`. По HTTPS на телефонах будут работать и микрофон для свечей, и камера для фотобудки.
